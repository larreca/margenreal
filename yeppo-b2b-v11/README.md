# Yeppo B2B CRM V11

V11 es la evolución operativa del CRM personal B2B de Yeppo.

## Objetivo
Una sola aplicación para priorizar cartera, gestionar recompra, reactivación y crecimiento, registrar resultados, formar clientes mediante Academia y asistir la preparación de contactos con IA.

## Reglas comerciales base
- Pedido >= $300.000 cuenta como señal B2B.
- Astroselling/Portal B2B es señal B2B.
- Recomendación de reposición: Bodega Central > 30 unidades.
- Las importaciones de fuente no deben borrar notas, tareas, pipeline ni gestiones manuales.

## V11
- Uso personal / single user.
- Mi Día.
- Dashboard + ventas mensuales.
- Ficha cliente 360.
- Pipeline y tareas.
- Funnel comercial.
- Academia B2B.
- Copiloto comercial.
- Centro de actualización de datos.
- Backup/restauración.
- Auditoría de importaciones.

La V10 actual permanece intacta en /yeppo-b2b-v10 mientras V11 se valida.
